# Compatibility

Maytrix 0.1.0 is a source preview and has not yet been validated in-game.

| Environment | Status | Notes |
| --- | --- | --- |
| Windows PCVR | Test pending | Intended build environment |
| SteamVR headsets | Test pending | Uses Unity XR input devices |
| Meta Quest through PCVR | Test pending | Requires the PC version and a working PCVR connection |
| Quest standalone | Not supported | This BepInEx project targets the PC game |
| Desktop without VR | Partial | F6 can toggle the menu, but controller interaction requires XR devices |

Compatibility can change when Gorilla Tag, Unity, or BepInEx updates. A release should state the exact versions used for its build and test.
